# Serie de informes · GDP-SLEP Studio

Índice interactivo de la serie de informes del Subdepartamento GDP-SLEP
(Dirección de Educación Pública).

- `index.html`: índice con buscador, filtros, índice de cada informe y botón de descarga.
- `docs/`: los informes en Word (.docx), en una carpeta por temática.

Carpetas por temática: `00-marco-legal`, `01-portal`, `02-validador-de-formularios`, `03-licencias-medicas` (con `versiones-anteriores`) y `04-ia-local`. Para actualizar un informe, reemplaza su archivo manteniendo el mismo nombre.

Clasificación de los informes: uso interno.
